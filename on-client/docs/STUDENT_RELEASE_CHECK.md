| 실제 실행 검증 | 6절의 명령 수준 확인(작성자가 새 폴더에서 실행)과 사용자가 연결 없음·예제 자료 모드에서 확인한 화면. 연결 설정이 필요한 기능은 포함하지 않습니다. |

## 10. 기다림(UNV) 목록

아래는 재현 완료로 적지 않았습니다.

1. 담당자의 native 호스트 설정 파일이 필요한 계정 연결과 AI 연결 (17단계). `NATIVE_HOST_DISABLED`로 막힘
2. 실제 AI 사건 설명 성공과 근거 ID 대조의 실제 화면 (18단계)
3. 실제 조치 준비·사람 확인·집행·결과 재조회 (19단계). 집행기 연결이 준비되지 않았고 `supportedActions`가 비어 있음
4. 실제 OSV 조회, `package-lock.json` 대조, `complete`·`partial`·`unverifiable` 상태 (20단계). `on-client`에는 `package-lock.json`과 의존성이 없고 조회 설정은 운영자가 준비함
5. 실제 SDP(기존 접속·XDR 시스템) 연결과 그 위의 13~16단계 실제 표시
6. 판정 `unknown`, 빈 목록, 시간 초과, 「미지원」 버튼, XDR 경보, 여러 건 기록의 실제 화면 (모의 점검만 있음)
7. 21·22단계 공식 접수 연결과 v1.0 표시
8. `-Port 5190` 실행, 서버 기동 지연 오류 재현, 서버 종료 직후 새로고침 표시

## 11. 기존 폴더와 기록의 보존 (확인 1)

- 원래 작업 폴더는 건드리지 않았습니다. 작업 트리가 깨끗하고 `on-20`, `on-21`, `on-22` 브랜치가 모두 있으며 `docs/` 문서가 그대로 남아 있습니다(작성자 확인).
